# نَسَق | NASAQ — المنصة الرقمية المتكاملة للتأهيل والتربية الخاصة

منصة **نَسَق (NASAQ)** مساحة عمل رقمية موجهة لأخصائيي التربية الخاصة، التخاطب واضطرابات النطق، التكامل الحسي، العلاج الوظيفي والطبيعي، والتدخل المبكر.

## المزايا والخدمات الرئيسية
- **إدارة ملفات المستفيدين (المعرفات الرمزية):** توثيق الملفات بالمعرفات الرمزية دون أسماء حقيقية لحماية الخصوصية، مع دعم الأرشفة والحذف المتسلسل الآمن.
- **مكتبة المهارات والمجالات الهرمية (11 مجالاً):** شجرة مهارات ومعايير قياس معيارية قابلة للتحويل المباشر إلى أهداف فردية.
- **صياغة الأهداف الذكية (SMART + IEP):** بناء أهداف إجرائية تشمل خط الأساس، الظروف، مستوى المساعدة، معيار الإتقان، التعميم، والمحافظة.
- **بنك الأنشطة وتخطيط الجلسات:** أنشطة متدرجة (تكييف للأسهل/الأصعب والتيسيرات الحسية) وخطط جلسات منظمة بأربع مراحل.
- **التسجيل اللحظي الميداني (Live Tracker):** تسجيل المحاولات واستجابات المساعدة لحظياً بواجهة لمس سريعة مع حفظ تلقائي للمسودة عند تبديل التبويبات أو تحديث الصفحة.
- **التوثيق السردي بعد الجلسة (Post-Session Narrative):** تدوين الملاحظات كتابياً أو بالإملاء الصوتي (مع اختيار اللهجة العربية)، وتنظيمها عبر الذكاء الاصطناعي عند توفره دون اختلاق أي وقائع سريرية غير واردة في نص الأخصائي.
- **التقارير القابلة للطباعة وتصدير PDF:** تقارير موجهة لأولياء الأمور أو تقارير IEP سريرية، مع دعم التصدير المباشر والطباعة الاحترافية A4 لحفظ نص عربي قابل للتحديد والبحث.
- **المكتبة السريرية للمراجع (EBP):** مراجع علمية معتمدة (ASHA, WWC, AFIRM, PBIS, ICF-CY) مرتبطة مباشرةً بصياغة الأهداف وتوليد الأنشطة.
- **الخصوصية والتخزين المحلي الآمن (PWA + IndexedDB):** حفظ مزدوج في `localStorage` و`IndexedDB`، قفل اختياري برمز PIN محلي، تحقق صارم من النسخ الاحتياطية عبر `Zod`، والعمل كتطبيق ويب تقدمي (PWA).

## التشغيل المحلي والاختبارات

### المتطلبات
- Node.js 22.6+ (مختبر على Node 22.23.2)

### الأوامر المتاحة
```bash
# تثبيت الحزم
npm install

# تشغيل الخادم وواجهة التطوير على المنفذ 3000
npm run dev

# فحص الأنواع (TypeScript)
npm run lint

# تشغيل الاختبارات الوحدوية
npm test

# بناء نسخة الإنتاج
npm run build

# تشغيل نسخة الإنتاج
npm start
```

## متغيرات البيئة (`.env`)
راجع ملف `.env.example`:
- `GEMINI_API_KEY`: مفتاح Gemini API في البيئة الخادمية فقط (اختياري؛ المنصة تعمل أيضاً بالمحرك الإكلينيكي المحلي دون انقطاع).
- `GEMINI_MODEL`: اسم نموذج Gemini (الافتراضي: `gemini-4-hydrogen`).
- `AI_ACCESS_CODE`: رمز وصول اختياري لحماية نقاط `/api/ai/*` من الاستخدام غير المصرح به.
